
# ScopeSentry – Application Workflow

## 1. Introduction

ScopeSentry provides a centralized platform for managing project requirements and controlling changes throughout the software development lifecycle.

## 2. User Roles

### Project Manager
- Creates projects.
- Uploads original agreements.
- Reviews extracted requirements.
- Analyzes change requests.
- Reviews cost and timeline impacts.
- Approves or rejects changes.

### Developer
- Views assigned projects.
- Reviews project requirements.
- Evaluates technical complexity.
- Provides effort estimates.
- Tracks approved changes.

### Client
- Views project commitments.
- Submits new requirements.
- Tracks change request status.
- Reviews additional costs.
- Approves or rejects proposed changes where authorized.

### Organization Admin
- Manages organization members.
- Assigns user roles.
- Controls organization access.

## 3. Complete Application Workflow

1. User Registration and Login
2. Organization Creation
3. Project Creation
4. Upload Original Project Agreement
5. AI-Based Requirement Extraction
6. Review Extracted Requirements
7. Establish Original Project Baseline
8. Submit New Change Request
9. AI-Based Scope Analysis
10. Impact Estimation
11. Manager Review
12. Client Approval
13. Update Project Baseline
14. Generate Reports and Audit History

## 4. Example Scenario

Consider a software company developing an e-commerce application.

### Original Project Scope

- User registration and login
- Product listing
- Shopping cart
- Order management
- Admin dashboard

### New Client Request

The client requests an online payment gateway and automatic invoice generation.

### AI Analysis

The system compares the new request with the original approved requirements.

| Analysis | Result |
|---|---|
| Payment gateway | New requirement |
| Invoice generation | New requirement |
| Existing scope match | Not found |
| Classification | Additional scope |

Illustrative impact estimate:

- Additional development time: 24 hours
- Additional cost: ₹12,000
- Deadline impact: 4 days

Actual estimates must be reviewed and confirmed by the project manager.

## 5. Approval Workflow

### Pending
The proposed change is waiting for authorization.

### Approved
The authorized reviewer approves the change.

### Rejected
The proposed change is rejected and does not modify the baseline.

### Clarification Requested
Additional information is required before a decision.

## 6. Baseline Version Management

When a change is approved:
- A new baseline version is created.
- Approved requirements are incorporated.
- Budget and deadline are revised where applicable.
- Previous baseline versions remain available.

## 7. Project Monitoring

The dashboard displays:
- Active projects
- Total change requests
- Pending approvals
- Estimated additional cost
- Project health score
- Recent project activities

## 8. Reports and Audit History

The system maintains:
- Original project agreements
- Requirement modifications
- Change request submissions
- Approval decisions
- Cost revisions
- Deadline changes

## 9. Expected Result

ScopeSentry provides transparent communication between clients, project managers and developers while protecting the original project commitments.
