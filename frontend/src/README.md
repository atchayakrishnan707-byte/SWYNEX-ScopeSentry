
# ScopeSentry Frontend Source

This directory contains the React and TypeScript source code for ScopeSentry.

## Planned Folder Structure

```text
src/
│
├── assets/
├── components/
├── pages/
│   ├── Landing/
│   ├── Login/
│   ├── Dashboard/
│   ├── Projects/
│   ├── Requirements/
│   ├── ScopeAnalysis/
│   ├── ChangeRequests/
│   ├── Approvals/
│   └── Reports/
│
├── services/
├── hooks/
├── context/
├── types/
├── App.tsx
└── main.tsx
```

## Responsibilities

- pages/: Main application screens.
- components/: Reusable interface components.
- services/: Backend API integration.
- hooks/: Reusable React hooks.
- context/: Authentication and shared application state.
- types/: TypeScript interfaces and types.
- assets/: Images, icons and other static assets.

## Frontend Technology

- React.js
- TypeScript
- Tailwind CSS
- React Router
- Recharts
